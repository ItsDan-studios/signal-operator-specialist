# User Context Template

Use this template when building `signal-state/user-context.md`.

## Rules

- Write only what is actually known
- Unknowns are allowed
- Use plain notes like `Not yet clear`
- Monthly and weekly goals are optional, not forced
- Keep every section practical and short
- This file should help triage, not become a life manual

## Template

```md
# User Context

## How to use this file
Use this file before triage to judge signal fit, likely distractions, and ranking tradeoffs for this user.

## Role and business context
[What the user does and what kinds of outcomes matter]

## Current operating period
[The active time horizon to optimize for right now]

- [stream]
```
