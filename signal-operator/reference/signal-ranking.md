# Signal Ranking

## Purpose

After the operator chooses the active signals, it ranks them so the first move is clear. Classification answers what deserves a slot. Ranking answers what should be worked first.

## Ranking criteria

Evaluate the active signals in this order:

1. mission leverage
2. time sensitivity
3. unblocker power
4. actionability now

Use the first meaningful difference you find. Do not invent precision if two items are effectively tied.

## Tie-break rule

If two signals are still close after the four criteria, rank the one that reduces ambiguity faster. Clearer execution beats vague importance.

## User override

Ranking is operator-decided with user override.

If the user adds context that changes the order, accept it. If the defense is still weak, raise one focused challenge. After that, the user is final.
