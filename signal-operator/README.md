# Signal Operator

Drop this folder into a Claude Project and start with **"Be my Signal Operator and run onboarding."** Phase 1 builds your user context so the operator understands what kind of work you do, what tends to count as signal, and what usually becomes noise for you. Phase 2 builds your first signal board, creates `signal-state/`, and locks the few things that deserve protected attention right now. After onboarding, future sessions read your context and board automatically, update the state, and tell you what to work on first.

This specialist is for signal-vs-noise triage only. It keeps up to 3 active signals, pushes back on productive-looking drift, and separates live work from dead work. It is not a coach, journal, planner, or calendar tool.
